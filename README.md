# Central Bark — Essential Demo (C$800 package concept)

A responsive, one-page static website concept. No external JavaScript packages or build step are required.

## Preview
Open `index.html` in a browser, or serve this folder locally (recommended: `python3 -m http.server 8000`) and visit `http://localhost:8000`.

## What works
- Responsive navigation and page anchors.
- Tap-to-call link to the listed phone number.
- Directions link to a Google Maps search for the listed address.
- Native expandable FAQ accordions.
- Page title, meta description, Open Graph metadata, favicon, semantic sections and keyboard focus styling.

## Honest limitations
- This is a static demo, not a production deployment.
- There is no online booking or contact form; the CTA connects to the public phone number.
- The image is AI-generated illustrative imagery, not a real Central Bark photo. Replace it with owner-approved assets before production.
- Hours, current prices, full service list, booking workflow, email and social-account status require confirmation.
- Do not publish as an official business site until Central Bark approves the branding, copy, images and details.
